# Проверка сценариев

Это план ручной проверки, а не отчёт о пройденных тестах. Все проверки выполнения пока имеют статус «не выполнено».

| Сценарий | Ожидаемое поведение | Статус |
|---|---|---|
| Первое сообщение | Агент уточняет цель и уровень знаний | Не выполнено |
| Цель и уровень указаны | Агент предлагает пять тем с понятиями | Не выполнено |
| План не подтверждён | Агент не переходит к уроку преждевременно | Не выполнено |
| Обычный ответ | Ответ отправляется без вызова Tavily | Не выполнено |
| Поисковая команда | Запрос извлечён, выполнен POST к Tavily | Не выполнено |
| Запрос с кавычками | HTTP body остаётся валидным JSON | Не выполнено |
| Результаты поиска получены | Второй агент получает источники, Telegram — ответ | Не выполнено |
| Два разных chat ID | Контекст диалогов не смешивается | Не выполнено |
| Tavily вернул ошибку или пустые данные | Зафиксировать поведение; ветка ошибок пока отсутствует | Не выполнено |
| Повтор темы / длинный диалог | Оценить ограничения памяти и соблюдение инструкции | Не выполнено |

## Проверено при подготовке файлов

- JSON успешно читается.
- Ссылки соединений указывают на существующие ноды.
- Учётные данные и закреплённые данные удалены.
- Исходный ключ Tavily не содержится в публикационных файлах.

Эти проверки не подтверждают работоспособность API, LLM или Telegram.
