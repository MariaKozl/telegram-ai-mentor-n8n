# Настройка прототипа

Инструкция описывает предполагаемый запуск. Совместимость с конкретной версией n8n необходимо проверить при импорте.

1. Импортируйте `ai-mentor.json` в n8n. Экспорт содержит AI Agent, Chat Model и Simple Memory; эти ноды должны быть доступны в вашей установке.
2. Создайте собственного Telegram-бота и подключите его credentials к Telegram Trigger и двум нодам отправки сообщений. Учётные данные автора удалены.
3. Подключите провайдера LLM к обеим Chat Model-нодам. Укажите правильный адрес провайдера и доступный идентификатор модели. При смене модели проверьте соблюдение формата поисковой команды.
4. В HTTP Request настройте авторизацию Tavily через credentials n8n. Удалите заглушку `Bearer REPLACE_WITH_TAVILY_API_KEY` из ручного заголовка Authorization, чтобы не отправлять два заголовка авторизации. Не сохраняйте настоящий ключ в публикуемом JSON.
5. Проверьте доступность Telegram webhook для вашей установки n8n.
6. Выполните сценарии из `verification.md` сначала в тестовом режиме. Проверьте, что поле `query` содержит только поисковый текст.
7. Включайте workflow после проверки credentials и диалогов.

Для повторного экспорта удаляйте credentials, ключи, webhook ID, метаданные аккаунта и данные выполнения. Не публикуйте переписки и личные данные пользователей.
